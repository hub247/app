# TrackFit v20

Nova identidade visual premium baseada no layout de Modo Foco aprovado.

Publique todo o conteúdo mantendo as pastas `assets/` e `dados/`.

## Áudios obrigatórios em assets/
- preparacao-para-o-treino.mp3
- audio-fim-treino.mp3
- audio-iniciar-treino.mp3

O app preserva `gymwp.v1`, plano alimentar, banco de alimentos e histórico local.

Principais mudanças: Design System global, Modo Foco em tela única, próximo exercício destacado, progressão por tempo, cálculo calórico segmentado e compartilhamento de Cardio com distância, tempo, pace/velocidade, calorias, melhor km e parciais.
