# TrackFit v18

Publique todo o conteúdo deste ZIP preservando as pastas.

## Áudio
Coloque o arquivo `audio-fim-treino.mp3` em `assets/`.

## Plano alimentar
Fonte editável: `dados/plano-alimentar/plano-alimentar-trackfit.xlsx`.
Arquivo lido pelo app: `dados/plano-alimentar/plano-alimentar.json`.

## Banco de alimentos
Fonte editável: `dados/banco-alimentos/banco-alimentos-200.xlsx`.
Arquivo lido pelo app: `dados/banco-alimentos/banco-alimentos.json`.

A v18 mantém `gymwp.v1`, carrega os JSON no GitHub Pages e guarda uma cópia local válida. Refeições montadas, favoritas e alimentos personalizados ficam persistidos no celular.
