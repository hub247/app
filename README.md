# TrackFit v15

Publique juntos `index.html`, `sw.js`, `manifest.json` e `icon.svg` no GitHub Pages.

Principais novidades: porções caseiras como padrão na Nutrição, descanso recolhido com instrução explícita para reabrir, período Semana na Evolução, relatório semanal detalhado e dois fluxos de compartilhamento: relatório visual e relatório completo para análise.

O app mantém a chave de armazenamento `gymwp.v1`, preservando os dados salvos da versão anterior. Para GPS no Safari, permita Localização e mantenha a tela ligada durante o Cardio.
